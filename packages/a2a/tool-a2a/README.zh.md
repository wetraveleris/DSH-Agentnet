# `@deepseek-ai/dsh-tool-a2a`

[English](README.md) | 中文

基于 `ctx.a2a` 的可选模型工具：`a2a_discover` 读取 Agent Card，`a2a_call` 通过 `ctx.fs` 读取所选本地文件并发送 A2A 任务，`a2a_task` 查询任务状态和 Artifact。

工具不会把本地路径发送给远程 Agent。它通过 DSH 文件系统服务读取内容，计算 SHA-256，预约短期一次性远程票据，上传字节，并且只把返回的不透明附件元数据记录到 A2A 调用中。这样模型可见请求可以从日志重建，同时不会把本地路径当作远程能力暴露。

工具通过有上限的 `ctx.fs.readBytes` 契约读取原始字节，并使用 A2A provider 配置的上传上限，因此图片和其他二进制文件会保持原始字节。断点续传暂缓。浏览器 UI 不调用该工具，只在 Settings 中发现 Agent。

## 模型体验

### A2A 工具

#### 模型看到的内容

模型看到 `a2a_discover`、`a2a_call` 和 `a2a_task`。系统提示词要求先发现 Agent，把本地文件路径传给 `a2a_call`，并用返回的任务 ID 调用 `a2a_task`。结果是结构化 JSON，在 Native 模式下投影为文本；本地路径不会发送给远程 Agent。

#### Token 影响

每次工具调用都会把 JSON 结果和系统提示词分区贡献给下一次请求。文件字节在提示词之外上传，不消耗提示词 token。

#### KV Cache 影响

静态工具描述和 A2A 指导保持在提示词前缀中；任务结果变化只会使工具调用之后的请求后缀失效。

## 已知限制与延后工作

- 面向模型的工具当前一次性上传完整文件；断点续传和大型 Artifact 存储暂缓。
- 远程 skill 代码不会下载或安装，工具也不提供支付、市场或信任评分。
